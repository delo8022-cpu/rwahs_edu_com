Install Python
python -m ensurepip --upgrade  # pip ইনস্টল বা আপডেট হবে
Create a Virtual Environment
python -m venv myenv  # ভার্চুয়াল এনভায়রনমেন্ট তৈরি হবে
Activate the Virtual Environment (Windows)
myenv\Scripts\activate  # Windows এ ভার্চুয়াল এনভায়রনমেন্ট অ্যাকটিভেট হবে
Activate the Virtual Environment (macOS/Linux)
venv\Scripts\activate.bat
venv\Scripts\activate
source venv/Scripts/activate
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser যদি অ্যাকটিভ না হয় তবে চালান
source myenv/bin/activate  # macOS বা Linux এ ভার্চুয়াল এনভায়রনমেন্ট অ্যাকটিভেট হবে
Install Required Packages
pip install -r requirements.txt  # সব প্যাকেজ একসাথে ইনস্টল হবে
Freeze Installed Packages
pip freeze > requirements.txt  # ইনস্টল করা প্যাকেজের তালিকা requirements.txt এ সেভ হবে
Check Installed Packages

pip list  # ইনস্টল করা প্যাকেজের তালিকা দেখাবে
Upgrade a Package
pip install --upgrade <package_name>  # প্যাকেজ আপডেট হবে
Uninstall a Package
pip uninstall <package_name>  # প্যাকেজ আনইনস্টল হবে
Create a Python Script
notepad myscript.py  # নোটপ্যাডে পাইথন স্ক্রিপ্ট তৈরি হবে
Run a Python Script
python myscript.py  # স্ক্রিপ্ট রান হবে
View Documentation for Python Module
python -m pydoc <module_name>  # মডিউলের ডকুমেন্টেশন দেখাবে
Check for Available Updates for Python
python -m pip install --upgrade pip  # pip আপডেট করা হবে
Create a Git Repository

git init  # নতুন গিট রিপোজিটরি তৈরি হবে
Clone an Existing Git Repository
git clone <repository_url>  # রিপোজিটরি ক্লোন হবে
Check Git Status
git status  # গিট স্ট্যাটাস দেখাবে
Add Changes to Git
git add <file_name>  # পরিবর্তন গুলি যোগ হবে
Commit Changes to Git
git commit -m "Commit message"  # কমিট মেসেজ সহ কমিট হবে
Push Changes to Remote Git Repository
git push origin <branch_name>  # রিমোট রিপোজিটরিতে পরিবর্তন পাঠানো হবে
